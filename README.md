# Daytime-and-nighttime-precipitation-unevenness
This repository contains the code for the manuscript titled "Opposing Contributions of Precipitation Amount and Temporal Concentration to Daytime–Nighttime Precipitation Unevenness Across ENSO Phases" submitted to Journal of Geophysical Research: Atmospheres.

./day_night_divide: Used to calculate daytime index and nighttime index for each gridcell

./calculate_unevenness_index: Used to calculate the relative entropy (RE) and unevenness index (UI) of daytime and nighttime precipitation for each gridcell
./code_for_figure: Used to plot the figures in the main manuscript.

We used data can be found at https://doi.org/10.6084/m9.figshare.31346695.v3
**Data Sources**
The Integrated Multi-satellitE Retrievals (IMERG) for Global Precipitation Mission (GPM) data is from  https://data.ucar.edu/dataset/gpm-imerg-final-precipitation-l3-half-hourly-0-1-degree-x-0-1-degree-v07. ERA5 data is from Copernicus Climate Change Service (C3S) Climate Data Store (CDS). DOI: 10.24381/cds.bd0915c6. Oceanic Niño Index (ONI) is from https://psl.noaa.gov/data/timeseries/month/DS/ONI/ accessed on (08/21/2026).
