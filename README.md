# Daytime-and-nighttime-precipitation-unevenness
This repository contains the code for the manuscript titled "Increasing contributions of extremes to daytime and nighttime precipitation unevenness" submitted to Geophysical Research Letters.

./day_night_divide: Used to calculate daytime index and nighttime index for each gridcell

./calculate_unevenness_index: Used to calculate the relative entropy (RE) and unevenness index (UI) of daytime and nighttime precipitation for each gridcell

./spatial_pattern_fig1: Used to generate Figure 1 showing spatial patterns of daytime and nighttime precipitation unevenness

./pearson_correlation_coefficient_fig2: Used to generate Figure 2 showing Pearson correlation coefficients between relative entropy (RE) and rainfall/rainfall_max (R/Rmax).

./region_fig3: Used to generate Figure 3 showing regional daytime and nighttime precipitation unevenness.

./extreme_fig4: Used to generate Figure 4 showing the relative contribution of extreme events to precipitation unevenness


**Data Sources**
The Integrated Multi-satellitE Retrievals (IMERG) for Global Precipitation Mission (GPM) data is from https://gpm.nasa.gov/. Climate reference regions are sources from https://www.ipcc-data.org/guidelines/pages/ar5_regions.html.
